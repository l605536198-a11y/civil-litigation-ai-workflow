# 民商事案件工作管理平台

面向中国大陆民商事诉讼的全生命周期 Legal AI Skill。覆盖诉前准备、诉讼程序和结案归档，并分别生成面向委托人、法官和承办律师的成果。

## 在线演示

GitHub Pages：启用后访问本仓库 Pages 地址。

在线页面仅作界面与流程演示，不上传案件文件、不调用本地 Agent。完整功能需要下载仓库并在支持 Skill 的桌面 Agent 中运行。

## 核心能力

- 案件主数据作为唯一事实源
- 五文件夹案件工作区
- 初步案件分析、接案笔录和证据清单
- 起诉状、代理意见、证据目录和案例检索报告
- 法院文书提取和程序期限管理
- 归档PDF合集、案件复盘PPT和脱敏微信推文
- 元典、北大法宝等法律检索 MCP 可选增强

## 安装

将 `skill/civil-commercial-litigation-workflow` 整个文件夹复制到桌面 Agent 的 Skills 目录。Codex 默认目录：

```text
C:\Users\你的用户名\.codex\skills\
```

重启后输入：

```text
请使用 $civil-commercial-litigation-workflow 建立一个新案件工作区。
```

详细步骤见 [详细使用说明](docs/详细使用说明.md)。

## 安全边界

- 关键事实、日期、金额和送达信息不得由模型猜测。
- 案例和法条必须可以追溯到实际检索来源。
- 期限、金额、对外文书和公开内容必须由律师人工复核。
- 真实案件材料应存放在律所批准的本地或私有环境。
- 公开演示和内容发布必须脱敏。
